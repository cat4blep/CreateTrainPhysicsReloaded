# Create Train Physics Reloaded 0.2.0-beta.3

This beta makes combustion fuel engine-aware and improves compatibility with
Steam 'n' Rails and Petrochem.

## Player-facing changes

- Different combustion engine types now keep independent fuel supplies. Fuel
  accepted by one engine can no longer power an incompatible engine elsewhere
  on the same train.
- Mixed compatible engines can operate simultaneously without sharing or
  duplicating fuel.
- Liquid refills drain the exact selected fluid from one Steam 'n' Rails tank.
  Liquid and item fuel are not consumed together, and no more than one new
  portion is acquired per train tick.
- Item fuel can be restricted to mounted storage with one exact custom name.
  The filter continues working for automated trains with unloaded carriage
  entities.
- Petrochem Gasoline and Diesel Engines are recognized as train motors with
  separate matching liquid-fuel profiles.
- Existing beta.2 train fuel is migrated without duplicating it between engine
  types.
- The server now synchronizes authoritative train power to clients, keeping the
  HUD correct in multiplayer when fuel is required.

## Modpack configuration

Engine-specific fluids, items, wildcard fallbacks, and refill priority can be
configured with the `create_train_physics:engine_fuels` NeoForge block data map.
A copyable example is included in `docs/examples/engine_fuels.json`.

The new `itemFuelStorageCustomName` common-config option defaults to `*`, which
preserves unrestricted item-storage selection.
